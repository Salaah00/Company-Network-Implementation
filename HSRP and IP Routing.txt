HSRP and IP Routing

On CORE-SW01

int vlan 10
no shut
ip add 192.168.10.3 255.255.255.0

standby 10 ip 192.168.10.1 

ip helper-address 10.11.11.38

ex

do wr

###################################################

int vlan 20
no shut
ip add 172.16.0.3 255.255.0.0

standby 20 ip 172.16.0.1

ip helper-address 10.11.11.38

ex

do wr
###################################################

int vlan 50
no shut
ip add 10.20.0.2 255.255.0.0  // WE GEIVE IT .2 BECAUSE THE HIGH IP ADD WILL BE THE ROUTER AND WE WANT THE CORE-SW02 TO BE THE ROUTER FOR THE VLAN 50

standby 50 ip 10.20.0.1

ip helper-address 10.11.11.38

ex

do wr

###################################################

int vlan 90
no shut

ip add 10.11.11.34 255.255.255.224
standby 90 ip 10.11.11.33

ex

do wr
